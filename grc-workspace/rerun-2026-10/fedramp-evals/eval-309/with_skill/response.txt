For a new cloud SaaS targeting federal customers in late 2026, my recommendation is: default to pursuing FedRAMP 20x / CR26 Certification Classes rather than a legacy Rev5 agency authorization package, but the right answer depends on a few specifics I'd want to confirm with you first.

Why 20x/CR26 is the better starting point for a new entrant right now:

1. It's now the primary, preferred pathway. Under CR26 (finalized June 25, 2026, mandatory January 1, 2027), FedRAMP 20x is explicitly positioned as the go-forward authorization model — continuous authorization built on Key Security Indicators (KSIs), machine-readable evidence, and modular API-driven submissions, rather than the traditional static SSP/SAP/SAR document set. A brand-new CSO built today has no legacy investment in the old SSP/POA&M Word-template process, so there's little reason to start there when the newer model is what FedRAMP wants everyone to move toward anyway.

2. There's a real, currently-open pipeline for a new entrant. Certification Class A opened August 3, 2026 — it's specifically designed as an entry point into the federal market via an existing external framework (initially SOC 2 Type II) through Program Certification. If you already have, or can obtain, a SOC 2 Type II, Class A gives you a comparatively fast on-ramp. Classes B and C opened August 31, 2026, so as of "late 2026" both pipelines are live and accepting new applicants. As a new SaaS company, Class A → then B/C within your 2-year transition window is a plausible, sequenced strategy.

3. Legacy Rev5 is entering wind-down. New Rev5 applications stop being accepted after June 11, 2027, and Rev5 fully sunsets December 31, 2028. Legacy FedRAMP Ready — historically a common way for a new CSP to signal readiness to agency sponsors — was already retired (relabeled Legacy FedRAMP Ready) on July 28, 2026, with no new submissions accepted. Starting a brand-new Rev5 legacy package now means investing in a track that has a visible expiration and reduced sponsor interest, plus you'd need an agency sponsor for the legacy Agency Authorization path, which is often the hardest part for a new, unproven vendor.

4. Machine-readable requirements favor 20x-native tooling anyway. The OSCAL/machine-readable mandate that hits Rev5 packages hard (no grace period for new Rev5 initial certifications from September 30, 2026) explicitly does NOT apply to FedRAMP 20x, which has its own machine-readable model built in from the start. Building your compliance program around 20x-native, API-driven evidence from day one avoids retrofitting OSCAL conversion into a legacy document set later.

Where I'd still want more information before finalizing this recommendation:
- What's your target Certification Class based on the sensitivity of federal data you'll handle? If you're aiming for anything High-equivalent (Class D), that pipeline isn't open yet — pilot expected late 2026, formal option early 2027 — so a High-impact new SaaS may have no choice but to work the legacy Rev5 High agency-authorization path in parallel while waiting for Class D to mature.
- Do you have an agency sponsor lined up, or are you relying on marketplace/self-driven entry? Class A's SOC 2-based entry doesn't require a sponsoring agency the way legacy Agency Authorization does, which is often a major advantage for a new vendor without existing federal relationships.
- Do you already have or can you quickly obtain a SOC 2 Type II? If not, factor in the time to get one before Class A becomes practically available to you.
- What's your actual timeline to first federal revenue? Since CR26 becomes mandatory January 1, 2027 anyway, even a legacy Rev5 start today would likely need to transition to CR26 classes relatively soon, so there's limited benefit to starting legacy unless you have a specific sponsor already committed to the old process.

Bottom line: for most new SaaS entrants in late 2026, start with FedRAMP 20x, targeting Class A (if you have or can get SOC 2 Type II) as a bridge to Class B or C within the 2-year window, rather than initiating a new legacy Rev5 package. Reserve the legacy Rev5 path for cases where you need a High-equivalent authorization immediately and can't wait for Class D to open, or where you already have a specific agency sponsor insisting on the traditional process. Confirm current pipeline status and eligibility criteria directly with FedRAMP PMO/fedramp.gov before committing significant budget, since class definitions and pipeline timing are still evolving through the CR26 rollout.
